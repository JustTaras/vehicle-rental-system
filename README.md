# vehicle-rental-system

# Розробка інформаційної системи бронювання та оренди транспортних засобів для туристичних подорожей

## Опис проєкту

Дипломний проєкт передбачає розробку веборієнтованої інформаційної системи для бронювання та оренди транспортних засобів, призначених для туристичних подорожей.

Система надаватиме можливість переглядати доступні транспортні засоби, обирати туристичні маршрути, перевіряти доступність транспорту та оформлювати бронювання. Передбачається підтримка різних типів транспорту, зокрема автомобілів, автобусів і велосипедів.

Також система передбачатиме автоматичний підбір транспортного засобу відповідно до параметрів подорожі, кількості пасажирів та інших критеріїв.

## Мета проєкту

Розробити інформаційну систему, яка автоматизує основні процеси бронювання та оренди транспортних засобів для туристичних подорожей, спрощує пошук відповідного транспорту та забезпечує зручне керування бронюваннями й орендою.

## Основні функціональні можливості

У межах проєкту планується реалізувати такі функції:

- Реєстрація та авторизація користувачів.
- Розмежування прав доступу відповідно до ролей користувачів.
- Перегляд каталогу доступних транспортних засобів.
- Фільтрація транспорту за типом та характеристиками.
- Перегляд детальної інформації про транспорт.
- Перегляд та вибір туристичних маршрутів.
- Перевірка доступності транспортних засобів на обрані дати.
- Бронювання транспортних засобів.
- Розрахунок вартості оренди.
- Автоматичний підбір транспорту відповідно до параметрів подорожі.
- Перегляд історії бронювань та оренд.
- Керування транспортними засобами, маршрутами та бронюваннями.
- Перегляд статистики використання системи.

## Ролі користувачів

У системі передбачається три основні ролі:

### 1. Клієнт

- Перегляд доступного транспорту.
- Пошук та фільтрація транспортних засобів.
- Перегляд туристичних маршрутів.
- Оформлення бронювання.
- Перегляд власних бронювань.
- Скасування бронювань.
- Перегляд історії оренд.

### 2. Менеджер

- Додавання та редагування транспортних засобів.
- Керування інформацією про доступність транспорту.
- Перегляд та підтвердження бронювань.
- Оформлення оренди.
- Контроль повернення транспортних засобів.

### 3. Адміністратор

- Керування обліковими записами користувачів.
- Керування транспортними засобами.
- Керування туристичними маршрутами.
- Керування тарифами.
- Перегляд інформації про платежі.
- Перегляд статистики роботи системи.

## Архітектура системи

Система розроблятиметься з використанням архітектурного підходу Model-View-Controller (MVC).

Архітектура передбачатиме розподіл програми на три основні компоненти:

- **Model** — моделі даних та логіка взаємодії з даними.
- **View** — представлення та інтерфейс користувача.
- **Controller** — обробка запитів користувачів та взаємодія між моделями й представленнями.

Для взаємодії з базою даних використовуватиметься Entity Framework Core.

## Структура бази даних

Для зберігання інформації планується використання реляційної бази даних Microsoft SQL Server.

Попередньо передбачається створення таких основних таблиць:

| Назва таблиці | Призначення |
|---|---|
| Users | Інформація про користувачів |
| Vehicles | Інформація про транспортні засоби |
| VehicleTypes | Типи транспортних засобів |
| Routes | Туристичні маршрути |
| RoutePoints | Точки туристичних маршрутів |
| Bookings | Інформація про бронювання |
| Rentals | Інформація про оренду |
| Payments | Інформація про платежі |
| Maintenance | Інформація про технічне обслуговування |

Остаточна структура бази даних буде визначена під час проєктування системи.

## Автоматичний підбір транспортних засобів

Однією з додаткових функцій системи буде автоматичний підбір транспортного засобу відповідно до параметрів туристичної подорожі.

Під час підбору враховуватимуться:

- Тип транспортного засобу.
- Кількість пасажирів.
- Характеристики транспорту.
- Тривалість подорожі.
- Доступність транспорту на обрані дати.

Підбір здійснюватиметься за допомогою алгоритму, побудованого на основі заданих критеріїв та правил відповідності.
